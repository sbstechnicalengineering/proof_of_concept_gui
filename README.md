# SBS Catalog (proof of concept)

McMaster-style product browser for Specialty Bolt and Screw parts. Static site: no server, no build step.

## Publish with GitHub Pages
1. Create a repository and upload the contents of this folder so `index.html` is at the repo root.
2. Settings > Pages > Source: **Deploy from a branch** > `main` / `/ (root)` > Save.
3. After a minute the site is at `https://<account>.github.io/<repo>/`.

## Embed
```html
<iframe src="https://<account>.github.io/<repo>/" style="width:100%;height:100vh;border:0" title="SBS Catalog"></iframe>
```

## Files
- `index.html`, `app.js`, `style.css` - the app
- `data/` - catalog data generated from the PIM (`tree.js`, `search.js`, `related.js`, one `cat_<id>.js` per category)
- `img/` - category images
- `.nojekyll` - tells GitHub Pages to serve the files as-is

Data is generated by `build_data.py`, `build_related.py` and `fetch_images.py` (kept outside this folder).
